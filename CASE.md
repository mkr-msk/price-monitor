# Кейс: мониторинг изменений каталога с отчётом в Excel

> Описание для портфолио — как для реального заказчика.
> Техническая часть: `README.md`, исходники и тесты в этом каталоге.

## Задача

Заказчику нужно следить за изменениями в каталоге: появляются ли новые товары,
что исчезло, меняются ли цены. Вручную это ежедневный обход и сравнение —
трудоёмко и с пропусками. Нужен автоматический мониторинг с понятным отчётом.

## Решение

Написан мониторинг на Python. Первый запуск фиксирует «снимок» состояния
каталога; последующие запуски сравнивают текущее состояние с прошлым и
формируют Excel-отчёт по листам: сводка изменений, новые позиции,
исчезнувшие позиции, изменение цен (было → стало).

Запуск обновления — одна команда; его можно поставить на расписание.

## Результат

- Снимок 50 страниц каталога — 1000 позиций.
- Отчёт «что изменилось» формируется автоматически при каждом запуске.
- Логика сравнения покрыта тестами (новые/исчезнувшие/изменение цен).

Пример сводки из реального прогона:

| Показатель | Количество |
|---|---|
| Новые позиции | 40 |
| Исчезнувшие позиции | 0 |
| Изменилась цена | 0 |
| Всего изменений | 40 |

## Почему это надёжно

- Позиции сравниваются по прямой ссылке — без ложных срабатываний на порядок.
- Цены хранятся в числовом виде — изменение вычисляется точно.
- Вежливый сбор: паузы между запросами, повторы при временных сбоях.
- Снимки хранятся локально — историю можно пересмотреть в любой момент.

## Что заказчик получает на руки

1. Инструмент мониторинга с историей снимков.
2. Excel-отчёт об изменениях по каждому запуску.
3. Инструкцию по установке на регулярный запуск (обновление по расписанию).
