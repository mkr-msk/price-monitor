# Price Monitor

Мониторинг изменений каталога: следит за позициями во времени и собирает
отчёт «что изменилось» — новые товары, исчезнувшие, изменение цен.

Решает типовую задачу «следить за ценами/наличием у конкурентов или в своём
каталоге»: первый запуск фиксирует состояние, последующие сравнивают с прошлым
и отдают Excel-отчёт об изменениях.

## Возможности

- сбор «снимка» каталога (url, название, цена, наличие, рейтинг);
- сравнение двух снимков: новые / исчезнувшие позиции, изменение цен;
- итог — Excel-отчёт с листами «Сводка», «Новые», «Исчезли», «Изменение цен»;
- повторные запуски: `snapshot` по расписанию, `report` — при необходимости;
- вежливость к сайту (паузы, повторы при временных ошибках).

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
# 1. зафиксировать состояние каталога
python main.py snapshot --pages 50

# 2. через какое-то время — снова
python main.py snapshot --pages 50

# 3. сравнить два последних снимка и получить отчёт
python main.py report --output data/report.xlsx
```

## Тесты

```bash
python -m pytest tests -q
```

Сравнение снимков — чистые функции, покрыты тестами (без сети).

## Устройство

```
collect.py    — сеть, пагинация, сбор снимка
diffing.py    — сравнение снимков (чистая логика)
report.py     — Excel-отчёт об изменениях
main.py       — CLI: snapshot / report
tests/        — тесты сравнения
```

Снимки хранятся в `data/snapshots/`. Адаптация под другой сайт — замена
селекторов и шаблона URL в `collect.py`.

Демо-прогон выполнен на стабильном публичном каталоге books.toscrape.com.
